# 🍔 WebNest Burguer

Site demonstrativo de uma hamburgueria artesanal desenvolvido como parte do portfólio da **WebNest**.

O projeto foi criado com foco em um design moderno, responsivo e visualmente atrativo, apresentando um cardápio de hambúrgueres, a história da marca e uma página inicial voltada para conversão

Versão 1.3

## 📸 Sobre o projeto

O **WebNest Burguer** é um projeto fictício desenvolvido para demonstrar as possibilidades de criação de sites profissionais para empresas do ramo alimentício.

A proposta foi criar uma identidade visual marcante, utilizando uma combinação de tons escuros, vermelho, laranja e tons claros para transmitir uma aparência moderna e destacar os produtos.

O site conta com:

- 🏠 Página inicial com seção Hero
- 🍔 Cardápio com 9 hambúrgueres
- 📖 Seção contando a história da hamburgueria
- 🛒 Botões para pedidos
- 📱 Design responsivo
- 🎨 Identidade visual própria
- ⚡ Layout adaptável a diferentes tamanhos de tela

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura e organização do site
- **CSS3** — estilização, layout e identidade visual
- **CSS Media Queries** — responsividade
- **Google Fonts** — tipografia
- **Unsplash** — imagens utilizadas no projeto
- **GitHub Pages** — hospedagem do site

### Fontes utilizadas

- **Oswald** — títulos e elementos de destaque.

## 🎨 Identidade visual

A identidade visual do WebNest Burguer foi construída utilizando uma paleta inspirada em hamburguerias premium, combinando cores escuras, tons quentes e superfícies claras.

| Cor      | Hexadecimal | Utilização                 |
| -------- | ----------- | -------------------------- |
| Preto    | `#0A0A0A`   | Header e elementos escuros |
| Creme    | `#F5E6D3`   | Fundo principal            |
| Vermelho | `#C1121F`   | Títulos e destaques        |
| Laranja  | `#F6A534`   | Botões e detalhes          |
| Cinza    | `#E5E5E5`   | Cards do cardápio          |

A proposta visual prioriza o contraste, a apresentação dos produtos e uma identidade consistente entre as diferentes seções do site.

## 🍔 Cardápio

O site apresenta 9 opções de hambúrgueres:

1. Classic Burguer
2. Bacon Supreme
3. Cheddar Melt
4. Crispy Chicken
5. Double Bacon
6. Fire Burguer
7. Onion Smash
8. Spicy Burguer
9. WN Supreme

Cada hambúrguer possui sua própria imagem, descrição e preço.

A apresentação do cardápio foi pensada para facilitar a visualização dos produtos e tornar a navegação mais intuitiva.

---

## 📖 Nossa história

A seção **Nossa História** foi criada para aproximar a marca do cliente, apresentando a origem fictícia da hamburgueria e mostrando que a proposta vai além de simplesmente vender hambúrgueres.

A ideia central da marca é:

> "Mais que um hambúrguer. Um momento para lembrar."

Essa seção complementa a identidade visual e ajuda a construir uma apresentação mais completa da marca.

---

## 📱 Responsividade e experiência do usuário

O site foi desenvolvido considerando diferentes tamanhos de tela, buscando manter uma navegação consistente em computadores, tablets e celulares.

Entre os aspectos considerados estão:

- Layout adaptável a diferentes resoluções.
- Organização dos produtos em cards.
- Hierarquia visual para títulos, descrições e botões.
- Navegação entre as seções.
- Apresentação visual dos produtos.
- Ajustes específicos para dispositivos móveis.

## 📁 Estrutura do projeto

```text
WebNest-Burguer/
│
├── images/
│
├── index.html
├── style.css
├── responsive.css
├── robots.txt
├── sitemap.xml
└── README.md
```

### Organização dos arquivos

- **`index.html`** — estrutura e conteúdo do site.
- **`style.css`** — estilos principais, cores e layout.
- **`responsive.css`** — regras de responsividade para diferentes dispositivos.
- **`images/`** — imagens utilizadas no projeto.
- **`robots.txt`** — orientações para robôs de rastreamento.
- **`sitemap.xml`** — mapa de URLs do site.
- **`README.md`** — documentação do projeto.

---

## 🔎 SEO técnico

O projeto inclui arquivos básicos de SEO técnico:

- **`robots.txt`** — fornece orientações de rastreamento para robôs compatíveis.
- **`sitemap.xml`** — lista as URLs incluídas no mapa do site.

Esses arquivos ajudam a organizar as informações técnicas do site, mas não garantem, por si só, a indexação ou o posicionamento nos mecanismos de busca.

## 🚀 Objetivo do projeto

O WebNest Burguer faz parte do portfólio da **WebNest**, com o objetivo de demonstrar conhecimentos em desenvolvimento front-end, criação de interfaces responsivas, organização de código e apresentação digital de negócios.

O projeto representa uma demonstração de como um site pode fortalecer a identidade de uma marca, apresentar produtos e facilitar a experiência dos visitantes.
